Thank you for installing {{ .Chart.Name }}!

The Nullify Kubernetes collector has been deployed as a CronJob and will collect information
about your cluster resources to help identify security vulnerabilities.

## IMPORTANT SECURITY INFORMATION
This collector gathers information about your Kubernetes cluster and stores it in an S3 bucket.
The data collected includes (but is not limited to):
- Cluster metadata
- Namespaces
- Workloads (Pods, Deployments, StatefulSets, DaemonSets, etc.)
- Service configuration
- Network policies
- RBAC configuration (Roles, RoleBindings, ServiceAccounts)
- PersistentVolumes and PersistentVolumeClaims

## Required AWS Permissions
The collector only uploads. Its role needs s3:PutObject on the Nullify bucket and
kms:GenerateDataKey on the KMS key; the connector's EKS integration (CloudFormation
EnableEKSIntegration, or Terraform enable_kubernetes_integration) grants both.
It never reads from the bucket.

## Useful Commands
You can verify the CronJob is created with:
  kubectl -n {{ include "k8s-collector.namespace" . }} get cronjob {{ include "k8s-collector.name" . }}

To check when the job is scheduled to run next:
  kubectl -n {{ include "k8s-collector.namespace" . }} get cronjob {{ include "k8s-collector.name" . }} -o wide

To check logs from the most recent job run:
  kubectl -n {{ include "k8s-collector.namespace" . }} logs job/$(kubectl -n {{ include "k8s-collector.namespace" . }} get jobs --sort-by=.metadata.creationTimestamp -o jsonpath="{.items[-1].metadata.name}")

To run the job manually:
  kubectl -n {{ include "k8s-collector.namespace" . }} create job --from=cronjob/{{ include "k8s-collector.name" . }} {{ include "k8s-collector.name" . }}-manual-$(date +%s)
